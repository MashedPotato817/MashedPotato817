# 图形素材说明

## 项目截图

`dsh-git-panel.png` 是 dsh-git-plugin 项目中独立测试仓库的真实 DSH Web Git 操作面板截图，供 Profile 展示功能。

- 来源：[docs/images/git-actions-dark.png](https://github.com/MashedPotato817/dsh-git-plugin/blob/9e072811a80d9b31348cf3639fd2b272ceb56ffb/docs/images/git-actions-dark.png)
- 来源版本：`9e072811a80d9b31348cf3639fd2b272ceb56ffb`
- 原始尺寸：343 × 862 px。
- SHA-256：`0e8d9a9156ff7405216594dc0d48290aeb5f64ea0c7c19ec296934e4cd8b3c5a`
- 本仓库直接复制原图，未裁剪、重绘或修改内容；README 仅控制显示宽度。
- 更新负责人：仓库维护者。更新截图时同步记录来源版本、尺寸和 SHA-256，并检查桌面与窄屏显示。

## 横幅和活动图

`profile-*.svg` 和 `project-*.svg` 为本仓库的原创矢量图形。横幅提供深浅色与静态版本；修改时同步检查四个版本及减少动态效果设置。

`activity-*.svg` 由 `scripts/update_activity.py` 生成。同一份贡献数据生成深浅色、桌面与窄屏、动画与静态共八个文件。展示总贡献、活跃天数和 31 天柱条，每 10 秒一轮：依次亮起约 1.65 秒，再静止约 8 秒后重播。零贡献日显示基线；README 根据减少动态效果设置选择静态文件。
